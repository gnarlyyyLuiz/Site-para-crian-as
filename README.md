# 🎈 Mundo dos Sons e Cores

Um site interativo e colorido criado com **HTML, CSS e JavaScript**, desenvolvido especialmente para crianças explorarem sons de animais, notas musicais e cores!

## 🚀 Funcionalidades
- 🐶 **Sons Interativos:** Sons divertidos simulados com Web Audio API ao clicar nos bichinhos.
- 🎨 **Troca de Cores:** Botão dinâmico que altera a cor de fundo da tela.
- 🎹 **Piano Mágico:** Um teclado interativo com notas musicais reais (Dó, Ré, Mi...).
- 📱 **Design Responsivo:** Funciona perfeitamente em computadores, tablets e celulares.

## 🛠️ Tecnologias Utilizadas
- **HTML5**
- **CSS3**
- **JavaScript (Vanilla)**

## 💻 Como executar o projeto
1. Clone este repositório no seu terminal ou baixe os arquivos.
2. Abra a pasta no **VS Code**.
3. Dê um duplo clique no arquivo `index.html` ou use a extensão *Live Server* do VS Code para rodar!
